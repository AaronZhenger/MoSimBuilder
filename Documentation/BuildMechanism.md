# Build Mechanism

Builder Currently has two mechanisms available,

* Arms
* Elevators

They can be accessed by adding a Build Arm, or Build Elevator script to an object.

These feature 
* the setpoints system at the top, 
* the ability to turn on or off the default models
* Automated model Subtypes
* weights
* size parameters

Finally they feature the Advanced Settings toggle,

This unlocks the mechanisms PID loop. allowing you to tune max speeds and tweak behaviour for specific mechs.
