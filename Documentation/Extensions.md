# Extensions

Builder Beta has a small set of "Extension scripts"

Currently there is
* Auto align
* Spawn Piece Target
* Attach At Startup

These are smaller scripts which extend the behaviour of another to acheive a specific behaviour not acheavable within the bounds of Builder.

Auto align is added on the same object as build frame, and has settings to align, it is NOT season specific and as such usis a simple set of options
Spawn Piece Target can be added to any object and simply serves as a reference point for and spawn stations on the field to target when spawning.
attach at startup is used for advanced Physics stuff. To minimize failures builder generates all physics elements at runtime, so this script is required to attach custom rigidbodies to a robot.
