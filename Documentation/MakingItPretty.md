# Making Robots pretty

Builder features a number of "parts libraries" that allow for decorating robots.

Lets decorate the kitbot we made in the last page.

Create a new Game Object,
Add a build tubing script to it, set the length to 30 inch and reposition it to be pointed up below the Piece State, and offset to one side.
Click the object you made, ctrlC and Ctrl V, to make another, and offset it to the other side,
Ctrl select both then copy and paste them, this allows you to copy mutliple things at a time.
While both are selected change the length to 20, then move them to the front

Add a new game object, and add a build plate to it, by default it makes an aluminum rectangle, this can be cahgned to a number of things.
We want a polycarb rectange, use the dropdowns to select that.

rotate the x axis to 20 degrees, then position it up higher so that it completes the triangle made by the uprights
then set the plate height to 30.5, and the width to 20.
Reposition it again, copy it and offset the new one up

Now copy the plate again, this time rotating it 90 degrees to the side.
set the width to 7 then reposition until its the side plate.
copy and put it on the other side
